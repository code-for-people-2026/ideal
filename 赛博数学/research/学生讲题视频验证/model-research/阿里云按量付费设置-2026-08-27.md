# 阿里云百炼按量付费设置核查（2026-08-27）

> 范围：阿里云百炼（Model Studio）华北 2（北京）地域，普通 API Key 调用 `qwen3.5-omni-flash-2026-03-15` 与 `qwen3.5-omni-plus-2026-03-15`。本文只记录官方规则和本次实验的本地错误证据，没有执行实名认证、充值、开关切换、提额或其他账户修改。

## 结论先行

百炼普通模型 API 默认就是**按量后付费**，不需要另外购买“按量付费套餐”。抵扣顺序是：免费额度 → 资源包 → 节省计划 → 按量付费；抵扣项用完后，普通 API 调用自动使用账户可用额度结算。前提是：

1. 已开通阿里云百炼；
2. 已完成阿里云实名认证；
3. 账户无欠费且可用额度充足；
4. 目标模型的“免费额度用完即停”处于**关闭**状态；
5. 当前 API Key/业务空间有目标模型调用权限。

官方依据：[账单查询与成本管理](https://help.aliyun.com/zh/model-studio/bill-query-and-cost-management)、[新人免费额度](https://help.aliyun.com/zh/model-studio/new-free-quota/)、[什么是阿里云百炼](https://help.aliyun.com/zh/model-studio/what-is-model-studio)。

但要特别纠正：本轮视频 2、视频 3 的失败**不是免费额度或余额不足**。两次均返回 HTTP 429、`insufficient_quota`、`You exceeded your current quota`。阿里云官方把这一组合定义为 TPS/TPM 速率限制；充值或开启按量付费不会提高 TPM。详见“本次 429 的正确诊断”。

## 用户需要检查的设置

以下操作应由账户所有者在电脑浏览器中自行完成；本文未代为操作。

### 1. 确认实名认证

打开[阿里云账号实名认证](https://myaccount.console.aliyun.com/cert-info)，确认状态为已认证。

- 未实名认证时，“免费额度用完即停”会被强制开启，开关不可见且不可操作；
- 实名认证和支付方式是两件事，完成实名并不等于已经绑定支付方式；
- 个人与企业账号应选择相应认证类型。

官方依据：[新人免费额度](https://help.aliyun.com/zh/model-studio/new-free-quota/)、[个人实名认证](https://help.aliyun.com/zh/account/verify-your-identity-individual-account)。

### 2. 确认百炼已开通

用阿里云主账号进入[百炼控制台](https://bailian.console.aliyun.com/cn-beijing/?tab=model)，选择华北 2（北京）。首次进入如出现服务协议，阅读并同意后即开通；若没有出现协议，官方说明通常表示已开通。

本次 API 已成功完成过一次 Qwen3.5-Omni-Flash 推理，因此当前账号、通用 API Key 和百炼服务实际上已可用，通常不需要再次“购买模型服务”。

官方依据：[首次调用千问 API](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)。

### 3. 关闭“免费额度用完即停”

必须在电脑端操作；百炼移动端暂不支持切换该开关。

1. 打开[百炼免费额度页面（北京）](https://bailian.console.aliyun.com/cn-beijing/?tab=costing-balance)；
2. 确认地域和业务空间与 API Key 一致；
3. 分别搜索：
   - `qwen3.5-omni-flash-2026-03-15`
   - `qwen3.5-omni-plus-2026-03-15`
4. 在右侧操作列把“免费额度用完即停”切为**关闭**；也可以选择“批量操作免费额度用完即停 → 批量关闭”；
5. 等待配置同步后刷新页面。阿里云提示状态同步可能存在延迟，关闭后仍无法调用时可等待约半小时再试。

判断方式：

- 显示“已开启”：需要关闭；
- 显示“未开启”：已经允许免费额度用完后转按量付费，无需再开通其他套餐；
- 显示“无免费额度”或“不支持开启”：这表示该模型没有可用免费额度或不支持此保护开关，不等于模型服务故障；普通可计费模型会按计费规则调用。

关闭后，超过免费额度的 Token 按控制台当前输入/输出价格计费，以按量后付费方式结算。官方提醒该状态可能导致欠费。

官方依据：[新人免费额度——免费额度用完即停](https://help.aliyun.com/zh/model-studio/new-free-quota/)、[模型用量](https://help.aliyun.com/zh/model-studio/model-usage-statistics)。

### 4. 检查账户可用额度和欠费

打开[费用与成本](https://billing-cost.console.aliyun.com/home)，确认：

- 账户可用额度不为负；
- 没有本账号下其他阿里云产品造成的历史欠费；
- 支付方式或现金余额满足后付费预占要求。

需要时由账户所有者自行使用[充值页面](https://billing-cost.console.aliyun.com/fortune/fund-management/recharge)。代金券不等同于现金可用额度；阿里云还可能先冻结当月消费对应的额度。充值和账务状态同步可能有数分钟延迟。

百炼按量付费采用“预占 + 月结”，不是每次请求完成后立即实际扣款；模型推理账单通常在请求结束后 2–10 分钟生成。

官方依据：[账单查询与成本管理](https://help.aliyun.com/zh/model-studio/bill-query-and-cost-management)、[错误码——Arrearage](https://help.aliyun.com/zh/model-studio/error-code/)。

### 5. 检查 API Key 和业务空间权限（仅在使用子业务空间时）

普通 API Key 创建时不需要选择具体模型；调用时由请求体的 `model` 参数指定模型。如果创建 API Key 时启用了“自定义权限/访问模型范围”，应确认两个 Omni 快照都在允许范围内。

- 默认业务空间：官方说明所有模型均可调用，且无法设置空间级模型限流；
- 子业务空间：超级管理员可在“业务空间管理 → 模型权限流控设置 → 模型列表”打开对应模型的“模型调用”权限，并检查该空间是否另设了请求数或 Token 限流；
- 未设置子空间限流时，空间共享主账号级模型限流；主账号下 RAM 子账号、业务空间和 API Key 的消耗合并计算。

本次已有同一 API Key 对 Flash 成功调用的证据，因此一般无需调整模型权限。若权限确有问题，常见响应也不会是本次的 `429 insufficient_quota`。

官方依据：[权限管理](https://help.aliyun.com/zh/model-studio/permission-management-overview)、[首次调用千问 API](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)。

## 本次 429 的正确诊断

### 错误类型不能只看英文中的 `quota`

| 现象 | 官方定义 | 应对 |
|---|---|---|
| HTTP 429，`insufficient_quota`，`You exceeded your current quota` | TPS/TPM Token 速率限制 | 等待、降低/错峰调用、减少单次 Token，或申请临时 TPM 提额 |
| HTTP 403，`AllocationQuota.FreeTierOnly` | 开启了“免费额度用完即停”，且免费额度已耗尽 | 实名后关闭该开关 |
| HTTP 400，`Arrearage`，`Access denied, please make sure your account is in good standing` | API Key 所属阿里云账号欠费 | 在费用与成本核查、结清欠费或充值 |
| HTTP 429，`CommodityNotPurchased` | 业务空间服务未订购 | 订购对应业务空间服务；本次没有出现此错误 |

官方依据：[百炼错误码](https://help.aliyun.com/zh/model-studio/error-code/)、[百炼限流](https://help.aliyun.com/zh/model-studio/rate-limit)。

### 为什么本次高度符合 TPM 限流

官方当前为北京地域的两个固定快照设置相同默认限流：

| 模型 | RPM | TPM（输入与输出合计） |
|---|---:|---:|
| `qwen3.5-omni-flash-2026-03-15` | 60 | 100,000 |
| `qwen3.5-omni-plus-2026-03-15` | 60 | 100,000 |

本地正式运行记录显示：

- 视频 1 × Flash 成功请求共消耗 156,197 Token；
- 视频 2 × Flash 在视频 1 完成后约 0 秒开始，上传约 10 秒后收到 429；
- 视频 3 × Flash 又紧接视频 2 失败后开始，约 15 秒后收到同样 429。

因此，结合错误码、单次 Token 和时间序列，可以高置信度判断为同一模型的 TPM/TPS 限流，而不是付费开关或余额问题。这是基于官方规则与本地运行证据作出的推断。

本地证据：

- [视频 1 Flash 运行元数据](../formal/video-01/qwen3.5-omni-flash-2026-03-15/run-metadata.json)
- [视频 2 Flash 运行元数据](../formal/video-02/qwen3.5-omni-flash-2026-03-15/run-metadata.json)
- [视频 3 Flash 运行元数据](../formal/video-03/qwen3.5-omni-flash-2026-03-15/run-metadata.json)

官方明确说明：限流与计费相互独立，**充值不会改变 RPM/TPM 阈值**；限流通常在一分钟内恢复。

### 对剩余实验的建议

在确认账户设置后，剩余请求应：

1. 每个模型内严格串行，不并发；
2. 同一模型的长视频调用之间至少等官方恢复窗口；由于本次单次请求约 156k Token，已经高于 100k TPM，工程上建议留 2–3 分钟而不只等 60 秒；这是保守执行策略，不是阿里云承诺的精确窗口；
3. 遇到 429 时不立即连续重试，使用指数退避；
4. Flash 和 Plus 是不同模型，官方说明不同模型的限流额度相互独立，但仍应避免瞬时突发；
5. 如果仍不稳定，可打开百炼控制台“模型 → 限流提额”，单击“提升模型临时限流额度”，选择目标模型并填写 Token/60 秒上限。官方说明提交后立即生效、有效 30 天；可选模型和上限以控制台弹窗为准。

官方依据：[百炼限流——恢复、模型独立限流和临时提额](https://help.aliyun.com/zh/model-studio/rate-limit)、[限流最佳实践](https://help.aliyun.com/zh/model-studio/rate-limiting-best-practices)。

## 账单和用量核查

### 账单

打开[账单详情](https://usercenter2.aliyun.com/finance/expense-report/expense-detail)：

1. 选择本月账期；
2. 产品名称筛选“大模型服务平台百炼”；
3. 根据“实例 ID（出账粒度）”核对 API Key ID、业务空间 ID、模型名称、输入/输出类型和调用渠道；
4. 特别核对此前已发送但被客户端中止的视频 1 × Plus 请求是否产生了账单。是否计费只能以阿里云最终账单为准。

### 用量

在百炼控制台顶部“模型”标签页进入“模型用量”，按模型或 API Key 筛选。官方说明用量统计大约延迟 1 小时，30 天以前的数据应改到账单详情查询。

可同时在“费用概览”设置月度消费限额、资金可用额度预警和短信/邮件告警。费用告警不是实时硬停开关；若要避免继续调用，需停止程序或撤销 API Key。

官方依据：[模型用量](https://help.aliyun.com/zh/model-studio/model-usage-statistics)、[账单查询与成本管理](https://help.aliyun.com/zh/model-studio/bill-query-and-cost-management)。
