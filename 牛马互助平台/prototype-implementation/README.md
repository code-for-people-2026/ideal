# 实施对照原型（IRP）

## 用途

帮助产品、设计、工程和测试共同理解当前 MVP 的：

- 角色与责任主体。
- 入口、主路径和页面级状态。
- Agent 与真人的权限边界。
- 数据可见范围和会话隔离。
- User Story ID 与关键验收结果。
