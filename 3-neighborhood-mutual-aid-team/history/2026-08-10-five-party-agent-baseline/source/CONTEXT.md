# 牛马互助平台

这是一个由消费者共享亲身服务经验、帮助彼此找到靠谱服务者的信任网络。平台记录和传递消费者拥有的经验与关系，不以替服务者获客为首要目标。

## Language

**消费者联盟**:
消费者为了降低共同的选择成本与踩坑风险，自愿共享亲身服务经验而形成的互助网络；服务者可以被连接和评价，但不是联盟的组织中心。
_Avoid_: 商家联盟、导购平台、获客平台

**近邻互助组**:
承载消费者联盟理念的用户侧产品与小程序名称。它强调既有邻里关系中的互助，不把“平台”或内部产品立场直接当作用户品牌。
_Avoid_: 消费者联盟 App、牛马互助平台 App

**亲历先行者**:
冷启动阶段由发起方人工组织、已经拥有可分享亲历的首批联盟成员。他们先贡献亲身消费经验并回应真实的外部求助，但不因推荐数量获得排名或特权。
_Avoid_: 骨干消费者、推广大使、分销员、达人

**外部求助**:
消费者在平台之外的既有关系场中提出的服务需求，例如邻居微信群里的询问。MVP 不负责产生或路由这类需求，而从联盟成员回应求助时开始介入。
_Avoid_: 站内需求、平台派单

**亲历推荐**:
联盟成员针对一条具体的外部求助，基于自己的真实消费经历向另一位消费者分享的有限经验；它证明“我用过并愿意告诉你”，不构成对服务者的无限担保。
_Avoid_: 商家推广、平台推荐、质量担保

**亲历推荐卡**:
亲历推荐在平台外关系场中的可携带载体，连接推荐人的消费记录、有限表述与服务者的下一步行动入口。它用于回应一条已存在的外部求助，不是供无目标群发的广告。
_Avoid_: 获客卡、广告卡、排行榜条目

**近邻系统 Agent**:
代表近邻互助组解释权限、整理需求并帮助用户从可见亲历中寻找服务者的智能体；它不代表服务者，也不替任何一方作出承诺。
_Avoid_: 桃子的 Agent、平台客服、撮合销售

**服务者 Agent**:
依据特定服务者已确认的信息进行接待、答疑和需求收集的智能体；接单、报价、服务判断与最终承诺仍由服务者本人负责。
_Avoid_: 服务者本人、近邻系统 Agent、自动接单机器人

**消费者 Agent**:
归属于特定消费者、依据其对当前服务事项的明确授权进行提问、整理、协商和请求确认的智能体；预约、购买、支付、接受变更和最终决定仍由消费者本人负责。
_Avoid_: 消费者本人、近邻系统 Agent、自动下单机器人

**混合会话**:
真人与 Agent 在同一服务事项房间中进行的可追溯对话。消费者、消费者 Agent、服务者、服务者 Agent 和近邻系统 Agent 都以独立身份参与；系统 Agent 负责事项边界和协作秩序，不代表任何一方。
_Avoid_: 单机器人客服窗口、没有责任主体的自动对话、全平台群聊

**服务事项房间**:
围绕一次具体亲历、服务需求或履约过程在近邻互助组小程序内建立的受限群聊。房间参与权来自该事项，不自动延伸为普通用户之间的站内社交关系。
_Avoid_: 用户私聊、社区大群、平台流量池

**平台外人际沟通**:
普通用户之间不围绕某个服务事项的社交沟通，继续发生在微信或其他既有关系场。近邻互助组只承载有明确事项、参与者和数据边界的服务事项房间。
_Avoid_: 泛社交、好友私聊、社区大群

**个人 Agent 会话**:
用户与归属于自己的 Agent 之间的持续对话，默认通过服务号发生。个人 Agent 经用户授权后也可以代表用户加入服务事项房间。
_Avoid_: 平台客服、公共机器人、用户本人

**他人 Agent 会话**:
用户在服务事项房间内与服务者 Agent 发生的受限对话。这不是隔绝的机器人私聊；消费者 Agent 可以同房自动沟通，服务者本人也可按事项边界查看和确认。
_Avoid_: 隔离的机器人私聊、匿名机器人、自动承诺

**Agent 协作**:
服务者 Agent 与消费者 Agent 围绕获得授权的服务事项交换消息、证据和任务状态。协作可在事项房间中对参与者可见，也可在后台执行；结果不自动等于所属真人的最终承诺。
_Avoid_: 用户群聊、后台自由对话、自动成交

**新需求对话**:
用户为另一项服务需求主动建立的独立会话，不默认继承已有服务者房间的内容或权限。
_Avoid_: 原会话分支、自动共享上下文

**亲历网络**:
由消费者拥有并在授权范围内可见的亲身服务经验所构成的信任网络，可用于寻找候选服务者，但不形成全局质量排行榜。
_Avoid_: 商家库、全站评分榜、广告投放池
