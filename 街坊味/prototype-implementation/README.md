# 实施对照原型

本目录面向产品、设计、工程和测试，保留两套角色原型：

- [总蓝图](./index.html)：产品闭环、角色入口和 User Story 分组。
- [桃子使用端](./prototype-taozi/)：菜品池、配送范围、周菜单、发布、订单、补单和收款记录。
- [顾客使用端](./prototype-customer/)：微信群入口、餐次选择、订单提交和订单状态。

原型负责解释页面和行为；若与 `product-decisions.md`、`CONTEXT.md` 或 `user-stories.md` 冲突，以文档为准。迁入前讨论稿中的“长期订单”和“收款截图辅助对账”不属于最新 P0：工程实现应采用“桃子维护订餐约定”和“按订单手工标记收款”。
