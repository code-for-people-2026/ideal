# 随口记

> 一句话方向：让用户用自然语言对话完成待办事项的记录、查询、整理、改期、提醒和完成。

「随口记」是一个与「楼道收一收」无关的独立项目；两者在仓库中顶层平级、相互独立。它不是社区事件处理工具，也不是「楼道收一收」的扩展。

## 当前阶段

本阶段只调研滴答清单（TickTick）的产品定位、功能地图和核心任务流程，并据此整理第一版“Todo 功能 → AI 对话意图”机会映射。当前不制作原型，也不展开完整产品定义。
