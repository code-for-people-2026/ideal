# 社区进入路径探索

本目录保存 2026 年 8 月围绕社区、街道、物业、业委会与公益组织所做的进入路径探索。

- `research/`：桌面研究，只代表文件标注日期的公开信息与判断。
- `outreach/`：实际接洽或沟通准备记录，含内部过程信息，不对外发布。
- `outreach-materials/`：当时用于说明近邻互助组的沟通材料，已经不是当前近邻闲置方案。
- `field-research/`：尚未执行的线下需求研究方案与模板。
- `prototypes/`：阶段性叙事页面，只用于理解探索过程。

## 当前结论

社区、街道与物业不是简单的产品获客渠道。进入真实场景前，需要先理解责任、许可、现有工作流、一线劳动成本与退出方式。这里的记录可以帮助 3.1 设计试点，但不能被直接当作合作背书或当前联系人清单。
