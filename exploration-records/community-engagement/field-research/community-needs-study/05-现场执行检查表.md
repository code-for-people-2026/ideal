## 2. 出发前硬门槛

- [ ] 已取得场地管理方书面或其他可留痕的明确同意，且日期、时间、地点、规模、物料一致。
- [ ] 同意内容不以开发、免费服务、合作、上线或试点承诺为交换条件。
- [ ] 场地管理方确认只接收匿名汇总，不要求居民名单、逐字回答、联系方式或关系网络。
- [ ] 一页报备说明中的所有 `【待确认/待填写】` 已填妥，批准状态不含糊。
- [ ] 现场至少 2 人；负责人、访谈、记录/安全角色和轮换已确定。
- [ ] 联系卡的保管人、用途、访问人、地点、销毁日如未填妥，已决定本场不收联系方式。
- [ ] 室外场地已核对天气和官方预警、雨备/改期；室内场地已核对容量、通风和噪音（不适用项已标明）。
- [ ] 工作人员完成话术、禁采信息、案例示范门槛、儿童/冲突/紧急和撤场演练。

任一未勾选：负责人签字确认“不执行”，不得抱着“先到现场再问”的想法进入受管理场地摆点。

## 5. 开场边界共读（T-10 分钟）

全员逐项口头确认：

- [ ] 今天先研究生活与已有办法，不先问 App 或示范案例。
- [ ] 社区互助是待验证方法；不愿互助、不需要软件、已有办法足够都是有效答案。
- [ ] 不给人贴“全职妈妈/照顾者”等标签，只记录其自愿描述。
- [ ] 不混写居民、场地管理方和社区组织需求。
- [ ] 不索取名单、身份证、精确住址、支付、健康详情、关系网络；不录音录像拍人。
- [ ] 不要求扫码、注册、关注、进群，不销售、收费或撮合交易。
- [ ] 不承诺开发、免费、合作、上线或试点；场地管理方允许场地不代表背书。
- [ ] 两个案例可以带到现场，但完成自由表达前保持覆盖/关闭；之后经同意只主动提供一个案例。
- [ ] 拒绝无需解释；受访者可跳题、随时停止。

## 7. 每位受访者流程检查

- [ ] 按本场固定间隔邀请，未挑选“看起来有空/像目标群体”的人。
- [ ] 使用 15 秒招呼语，说明不卖东西、匿名、无需扫码。
- [ ] 完成 30–60 秒说明，问到明确口头同意。
- [ ] 让对方选择短版/深版，可跳题或停止。
- [ ] 从最近生活经历开始，先问现有办法及其好处。
- [ ] 问到愿意/不愿意互助和无需软件条件。
- [ ] 不记录禁采信息；对方主动说出时已礼貌打断。
- [ ] 核心访谈前未展示案例；如展示，三道门槛已满足，并记录案例名称、由谁提出和前后变化。
- [ ] 结束时复述并请纠正，不承诺结果。
- [ ] 后续联系在访谈结束后独立选择，答案/联系卡立即分袋。

## 9. 秩序、儿童与紧急情况检查

- [ ] 候访不超过一组，无聚集、插队或阻挡通行。
- [ ] 未独立招募或记录未成年人；未给儿童礼物或拍照。
- [ ] 成人携儿童时未由工作人员代看；其需要照护时立即暂停。
- [ ] 不介入居民、场地管理方、商户或家庭纠纷；投诉由负责人接手。
- [ ] 纸面记录未离开工作人员、未被围观或拍摄。
- [ ] 天气/风力/地面/展架持续安全，噪音允许听清自愿说明。
- [ ] 现场未销售、收费、收款、撮合或商业引流。

### 立即停止/撤场触发器

- [ ] 场地管理方同意无法出示、被撤回或现场超范围
- [ ] 场地管理方/安保要求停止
- [ ] 通道、消防、车辆、儿童或设备安全受影响且不能立即纠正
- [ ] 雷电、强风、积水、高温不适、明显恶劣天气
- [ ] 围观/噪音使同意或回答不能基本私密
- [ ] 冲突、骚扰、健康事件、人身危险
- [ ] 资料遗失、被看见、误收敏感信息或联系信息混袋
- [ ] 团队开始推介、承诺或无法维持研究边界
- [ ] 最低两人值守无法维持或团队明显疲劳

触发任一项：停止邀请 → 结束/中止在访 → 双袋封存 → 联系现场负责人/场地管理方 → 按批准路线撤场 → 记录事件。不得为“做完样本数”继续。
