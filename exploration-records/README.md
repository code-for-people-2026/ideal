# 探索记录 · Exploration Records

这里集中保存过去两个月中没有成为当前产品需求、但仍有复用和复盘价值的 Session 成果。

它与产品目录的区别是：

- 产品目录描述当前或某一明确阶段的产品边界。
- 探索记录保留当时的问题、假设、沟通与材料，不代表结论今天仍然成立。
- 任何探索成果要重新进入产品，必须先经过核验并写成新的产品决议。

## 目录

- [`SESSIONS-2026-07-08.md`](./SESSIONS-2026-07-08.md)：2026 年 7–8 月工作总览与救援清单。
- [`community-engagement/`](./community-engagement/)：社区、街道、物业、业委会、公益组织等进入路径的研究与沟通记录。
- [`other-opportunities/`](./other-opportunities/)：未进入当前方向的其他业务机会。
- [`product-narrative/`](./product-narrative/)：阶段性品牌与产品叙事页面。

## 使用边界

接洽记录可能包含对接人的称呼、沟通时间与转述，只供内部复盘。再次联系前要重新核验身份、职务、项目状态与公开联系方式；对外发布前必须去标识化。

研究文件只代表其标注日期的桌面研究或当时沟通，不是法律意见、政府正式说明、合作承诺或当前采购状态。
