# 1 近邻闲置（Neighborhood Exchange）

> 当前状态：探索中的最小切口
>
> 这是“1 近邻闲置 → 3 近邻互助组 → 9 牛马互助平台”产品演进蓝图的当前切入点。

近邻闲置从一个小区里的低风险普通物品流转开始，让邻居完成一条足够短、能够在线下真实发生的路径：

> 发布 → 分享到邻居群 → 表达意向 → 约定线下交接 → 标记完成

这一阶段不是放弃近邻互助组或牛马互助平台，而是先验证最基础的邻里连接能否发生、能否重复。

## 当前边界

- 只服务一个小区。
- 只处理低风险普通物品。
- 线上只辅助展示、表达意向和约交接；交接在线下由居民自行完成。
- 不承诺交易担保、物流、支付、鉴定或纠纷仲裁。
- 技能、维修、街坊味等“闲置本领”只作为未来方向说明，不进入首期运行。

详细决议见[《从近邻互助组收缩到近邻闲置》](./product-decisions/2026-09-02-从近邻互助组收缩到近邻闲置.md)，领域语言见 [`CONTEXT.md`](./CONTEXT.md)。

## 当前交付边界

仓库保留业务范围与领域语言，并收录 [微信群闲置整理原型](./prototype-wechat-idle/README.md)：从两个指定群的既有记录整理物品，分别提供带密码的群页面、照片与发布人详情。它用于验证群内闲置发现与浏览，尚未实现自主发布、表达意向、交接约定等完整首期流程，不改变上述产品边界。原型以独立 Vercel 与 Neon 环境运行，真实聊天、照片和访问凭据保留在本地或受保护服务中，不随仓库发布。
