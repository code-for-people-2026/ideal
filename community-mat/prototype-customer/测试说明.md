# 近邻互助组 · 客户体验原型测试说明

> 对象：[客户体验原型（CEP）](./index.html)
> 版本：2026-07-31
> 单次时长：15–20 分钟
> 本轮只验证价值理解、信任边界和高光路径，不验证真实 AI、微信接口或付费转化。

## 1. 目标参与者

- 居住在有微信群、业主群或熟人互助群的社区。
- 最近半年曾在群里求助、推荐或寻找本地服务。
- 不是本项目成员，未提前阅读产品决议。

建议首轮 5 人；若连续出现同一种误解，先修改原型再招下一轮。

## 2. 三个学习问题

1. 不解释产品时，参与者能否在 30 秒内说出“具体消费者分享本人亲历，帮助别人找服务者”？
2. 参与者走到亲历详情后，能否说清楚“谁推荐、依据是什么、这是否等于平台担保”？
3. 参与者进入混合会话后，能否区分桃子本人、桃子的 Agent 和近邻系统 Agent，并知道谁能作最终承诺？

## 3. 测试任务

主持人只读任务，不介绍按钮位置和产品规则。

### 任务 A · 判断它是什么

> “这是你第一次看到这个产品。先随便看看，然后告诉我：它想帮谁解决什么问题？”

记录：

- 第一句复述是否包含“消费者 / 邻居”“本人用过 / 亲历”“找服务者 / 少踩坑”。
- 是否误解为点评网站、广告平台、服务者获客工具或万能 AI 助手。

### 任务 B · 从微信群求助到做出判断

> “你是小李，厨房水管漏水，想找这两天能上门的维修师傅。请看看这条邻居回复，决定是否值得继续联系。”

记录：

- 是否独立打开亲历卡。
- 是否找到推荐人、次数、最近时间、确认状态和需求匹配点。
- 是否注意到“无推荐收益”和“非平台担保”。
- 犹豫、回退、误点和主持人介入发生在哪里。

### 任务 C · 确认责任并完成预约

> “你想确认明天下午能否上门、费用是多少，并完成这次维修预约。”

记录：

- 是否理解服务者 Agent 可以采集、初判、草拟和发卡，但不能独立确认时间、价格和最终承诺。
- 是否找到彭师傅本人，并理解系统 Agent 不代表彭师傅。
- 是否理解当前房间不会暴露自己的其他需求或聊天。
- 是否看懂预约卡由服务者 Agent 整理发送，但时间、价格和服务承诺已经由服务者本人确认。

## 4. 成功门槛

首轮原型进入下一阶段前，至少满足：

- 4/5 参与者无需主持人解释即可完成任务 B。
- 4/5 能正确复述三个记忆点中的至少两个：真人亲历、Agent 不替人承诺、数据不出售。
- 5/5 不把 Agent 消息误认为真人已经作出最终承诺。
- 5/5 不把亲历卡误认为平台质量担保或付费广告。

偏好性评价（“喜欢 / 好看 / 想用”）只作辅助，不替代实际行为。

## 5. 原型中被模拟的内容

- 微信群、用户身份、消费次数、时间、服务菜单和聊天内容全部为合成数据。
- OCR、语音、推荐匹配、Agent 回答和真人在线状态均为预制结果。
- 小程序分享、跨小程序跳转、通知、授权、月卡和支付没有连接真实接口。
- 页面顺滑不代表真实网络延迟、异常、权限和安全问题已经解决。

主持人在测试前只需说明“这是不会产生真实操作的原型”；不要提前解释哪些 AI 能力是假的，以免影响自然观察。任务结束后再完整披露模拟范围。
