# 楼道收一收

这个领域管理单栋楼内由住户上报、由师傅完成的楼道回收与清扫待办。它不管理每位住户的独立订单，也不是通用工单系统。

## Language

**上报**:
住户扫码后发出的楼层事项通知。每次扫码都代表一次新的上报；同一上报可以采用匿名或实名身份模式，但它仍不是一份需要逐单履约的个人订单。
_Avoid_: 进入楼层、待收确认、个人订单

**上报类型**:
上报所需的处理动作，仅分为“回收需求”和“打扫需求”。类型不同的上报分别形成待办，不互相聚合。
_Avoid_: 事件分类、紧急程度、服务流程

**上报身份模式**:
住户提交上报时选择的身份关系，仅分为“匿名上报”和“实名上报”；它与“回收需求 / 打扫需求”的上报类型相互独立。
_Avoid_: 用户类型、工单类型、是否留电话

**匿名上报**:
不与住户身份建立关系的上报。它可以触发公共待办和处理记录，但不进入上报人的个人记录，也不向上报人提供通知、结果反馈或持续追踪。
_Avoid_: 游客订单、隐身投诉、无效上报

**实名上报**:
与已确认住户身份建立关系的上报。上报人能够持续查看所关联事项的状态和结果，并对结果补充反馈；其身份不因此向其他居民公开。
_Avoid_: 公开姓名上报、强制留电话、实名投诉

**待办事项**:
师傅尚未完成的楼层事项。同一楼层、同一事项类型在未完成期间聚合为一条待办，保留上报次数和最近上报时间。
_Avoid_: 回收轮次、订单、工单

**现场补充**:
附着在本次上报上的可选照片或留言，用来帮助师傅找到位置或理解现场情况。
_Avoid_: 子任务、事件详情

**完成**:
师傅确认一条待办事项已经处理完毕。完成后的新上报会形成新的待办，不与已完成事项混合。
_Avoid_: 销单、关单、关闭事件

**现场没发现**:
师傅到达楼层后，当前没有发现需要回收或打扫的事项。它同样会从待办中勾销，但只记录本次到场结果，不判断住户是否恶意上报，也不向住户展示“假消息”标签。
_Avoid_: 假消息、虚假上报、恶意上报

**清洁完成记录**:
能够说明一线保洁在特定时间和楼层完成过清洁的可核验记录；它用于呈现劳动结果和区分后续再次污染，不等于对该区域此后持续洁净作出保证。
_Avoid_: 保洁自证、免责证据、打卡考核

**清洁后再次污染**:
一线保洁完成清洁后，同一位置因宠物、人员活动或其他新原因再次变脏。它与“此前没有打扫”是两种不同事实。
_Avoid_: 保洁没打扫、保洁失职（未经核实）

**处理可见性**:
实名上报人能够知道所关联事项是否被看见、是否处理、处理结果是什么，并对结果补充反馈；匿名上报不建立这种个人追踪关系。去身份化的公共处理事实仍可用于协作和监督。
_Avoid_: 后台状态、工单围观、已回复即办结

**监督证据链**:
从居民上报、物业承接、一线处理到结果反馈的连续事实记录，使业委会能够监督事项是否真正执行，同时不直接介入物业日常派工。
_Avoid_: 业委会派工、物业考核后台、投诉排行榜

**回收补充收入**:
一线保洁通过收取并出售可回收物获得的劳动外补充收入，每月数百元也可能具有实际意义。试点应保护真实的定向回收机会，不能把这项收入描述成无关紧要的“小外快”。
_Avoid_: 小外快、废品福利、物业工资替代

**居民触达与参与入口**:
居民因为解决日常小事而自愿、持续使用的低门槛入口，业委会可在明确授权范围内借此传达共有事务并邀请参与；它不是流量资产，也不赋予业委会操纵居民意见的权力。
_Avoid_: 流量入口、私域流量、业主用户池

**一线保洁**:
实际承担小区清扫、垃圾收运与现场卫生工作的劳动者，是楼道收一收首先需要服务的人；试点不能以增加其无偿操作、监控压力或收入损失来换取管理便利。
_Avoid_: 保洁资源、执行端、被考核对象

**保洁现场主管**:
负责一线保洁的楼栋分工、班次协调和日常问题处理，是保洁公司经理与一线保洁之间的独立协作角色；可以参与流程设计，但不能单方面把协作记录转为绩效考核。
_Avoid_: 保洁公司经理、一线保洁、系统管理员

**回收参与业主**:
在小区内自行收集可回收物的业主，其中部分为老年居民；他们与一线保洁可能围绕可回收物收益和收集方式产生冲突，但不能仅因年龄或行为被污名化。
_Avoid_: 捡垃圾老人、拾荒老人、麻烦业主

**非预约楼层回收**:
未按小区共同规则或具体住户请求，在不固定时间逐层寻找并收取物品的行为；它会造成物品是否已被弃置、由谁收取以及错拿后如何追溯的不确定性，无论实施者是业主还是保洁都适用同一规则。
_Avoid_: 扫楼捡垃圾、老人偷拿、保洁顺手拿走

**定向回收委托**:
住户主动将自己有权处置的特定可回收物交由指定的一线保洁收取。楼道收一收帮助这项自愿交接更快发生，不以全体业主先形成统一规则为前提。
_Avoid_: 公区回收权确权、强制统一回收、业主大会授权

**互惠提醒通道**:
住户用回收提醒帮助一线保洁减少空跑并获得回收机会，一线保洁用清扫待办帮助住户更快传达楼层卫生需求；这是双向降低信息成本，不是用可回收物交换物业应履行的清扫服务。
_Avoid_: 居民报事平台、物业派工系统、废品换保洁

**试点责任结构**:
运行型试点由业委会发起并监督、物业承担运营责任、保洁公司协调人员、一线保洁共同设计，码成工提供调研与技术支持；业委会秘书负责牵线协调，不替代物业日常派工。
_Avoid_: 码成工代运营、业委会直接派工、绕过物业试点
