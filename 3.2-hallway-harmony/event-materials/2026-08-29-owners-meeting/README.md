# 2026-08-29 业主大会宣传志愿活动

## 事情背景

小区业委会计划在小区门口设点，向业主宣传本年度业主大会。业委会秘书邀请项目发起人以志愿者身份参与，并利用活动间隙与业委会委员、物业进一步沟通“楼道收一收”的实际需求。

这次沟通的重点不是推动项目立项，而是了解小区现有的楼道保洁、可回收物处理和问题反馈流程，特别是一线保洁人员使用工具时的投入产出比。

## 本次材料

- [`楼道收一收-试点沟通稿.pdf`](./楼道收一收-试点沟通稿.pdf)：A4 单页沟通材料，包含原型二维码、初步协作流程、参与角色、最小试点范围和现场调研问题。

该 PDF 用于与业委会、物业及一线保洁人员进行小范围讨论，不是业委会的正式宣传文件，也不代表项目已经获批。

## 现场希望确认

1. 当前楼道保洁和可回收物处理的真实工作流程；
2. 信息传递中最容易遗漏或反复沟通的环节；
3. 保洁人员愿意接受的操作方式和额外时间成本；
4. 物业在人员协调、培训和管理方面的投入；
5. 卫生改善、沟通减少和回收收益能否覆盖投入；
6. 是否值得选择一个楼栋开展约两周的免费小范围试点。

## 原型

[楼道收一收 · 住户端交互原型](https://ideal.codeforpeople.cn/hallway-harmony/)

## 活动后的沟通结果

业委会委员原则上支持继续了解“楼道收一收”，但业委会不能替代物业运营，也无法为前期调研提供大量执行支持。下一步需要与物业项目负责人、保洁现场主管和一线保洁沟通，确认现有流程、实际痛点和投入产出。

委员同时反馈，本次 A4 材料没有先讲清楚“现实中谁遇到了什么问题、项目具体要解决什么”，而过早进入了流程、角色和试点方案。因此，该 PDF 作为本次活动的历史材料保留，不再作为后续统一沟通稿。

后续沟通改用[《楼道收一收 · 分角色沟通稿》](../../communication-materials/分角色沟通稿.md)，分别面向一线保洁、物业、业委会和普通业主与居民，从各自痛点开始说明问题，再讨论方案与试点边界。

与物业正式沟通前，使用[《物业沟通前痛点假设与访谈提纲》](../../communication-materials/物业沟通前-痛点假设与访谈提纲.md)，先验证物业是否存在值得解决的问题，不把“人工转述麻烦”等项目方猜测当成既定事实。
