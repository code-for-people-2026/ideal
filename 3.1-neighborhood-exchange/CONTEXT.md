# 近邻闲置领域语境

近邻闲置（Neighborhood Exchange）帮助同一小区的居民发现并完成低风险普通物品的线下流转。它是产品演进蓝图的 3.1 阶段，不是通用二手交易平台。

## Language

**闲置物品**：
居民已经拥有、当前不再需要，且适合在邻里之间线下交接的低风险普通物品。
_Avoid_: 商品库存、商家货品、闲置本领

**发布**：
物主整理一件闲置物品的必要信息，生成一条尚未对外传播的闲置记录。
_Avoid_: 上架商品、开店

**邻里分享卡**：
居民主动分享到既有邻居群的物品信息载体。产品不代替邻居群，也不自动群发。
_Avoid_: 广告投放、平台分发、推荐流

**表达意向**：
邻居表示希望进一步了解或接收某件物品，但尚未形成交易承诺，也不自动锁定物品。
_Avoid_: 下单、抢购、竞拍

**交接约定**：
物主和有意向的邻居自行确认线下交接时间与大致地点。平台只记录双方输入的信息，不担保任何一方履约。
_Avoid_: 平台配送、平台派单、平台担保

**流转完成**：
参与者在实际线下交接后，将该物品标记为不再可流转。它只说明交接已由用户确认，不构成质量认证。
_Avoid_: 平台验收、担保交易成功

**闲置本领**：
居民愿意分享或有偿提供的技能与服务，例如维修、手工、打印或做饭。它是未来可能纳入近邻互助组的供给类型，**不属于近邻闲置首期运行范围**。
_Avoid_: 首期闲置物品、当前可发布类目

**近邻互助组（Neighborhood Mutual Aid Team）**：
在近邻闲置被验证后，可能由重复流转、真实亲历与邻里身份逐步形成的持续互助单元。“互助组”是专有名词，英文固定使用 `mutual-aid-team`。
_Avoid_: mutual-aid-group、交易群、商家联盟

## 首期状态

```text
未分享 ──分享──> 可流转 ──收到意向──> 有人感兴趣
                                      │
                                      └──约交接──> 待线下交接 ──双方确认──> 已完成
```

表达意向可以被撤回或不被接受；首期原型暂不验证冲突意向、纠纷、支付或信用分。

## 边界

- 一个小区，不验证跨小区流转。
- 低风险普通物品，不纳入药品、食品、票券、高价值鉴定品或依法限制流通的物品。
- 线上建立联系，线下自行交接。
- 技能、维修、街坊味等闲置本领只出现在未来说明中。
