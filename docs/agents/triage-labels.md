# 分诊标签

Skill 使用五个标准分诊角色。本文件把这些角色映射到本仓库 Issue 跟踪器中的实际标签字符串。

| `mattpocock/skills` 中的标签 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要维护者评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可交给离线 Agent |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 Skill 提到某个角色（例如“添加可交给离线 Agent 的分诊标签”）时，使用表中对应的标签字符串。

如果 Issue 跟踪器采用了不同词汇，修改“本仓库标签”一列与之一致。
