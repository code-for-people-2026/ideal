# 楼道收一收

这个领域管理单栋楼内由住户上报、由师傅完成的楼道回收与清扫待办。它不管理每位住户的独立订单，也不是通用工单系统。

## Language

**上报**:
住户扫码后发出的楼层事项通知。每次扫码都代表一次新的上报，住户不需要跟踪后续处理状态。
_Avoid_: 进入楼层、待收确认、催单

**待办事项**:
师傅尚未完成的楼层事项。同一楼层、同一事项类型在未完成期间聚合为一条待办，保留上报次数和最近上报时间。
_Avoid_: 回收轮次、订单、工单

**现场补充**:
附着在本次上报上的可选照片或留言，用来帮助师傅找到位置或理解现场情况。
_Avoid_: 子任务、事件详情

**完成**:
师傅确认一条待办事项已经处理完毕。完成后的新上报会形成新的待办，不与已完成事项混合。
_Avoid_: 销单、关单、关闭事件
