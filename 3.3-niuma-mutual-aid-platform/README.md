# 牛马互助平台 · Niuma Mutual Aid Platform

> 状态：长期愿景，保留；平台级实现暂缓。

牛马互助平台并没有被放弃。它仍然代表码成工希望长期建立的数字基础设施：让普通人拥有自己的数据、亲历关系和互助网络，并共同分享由此产生的价值。

当前不直接建设平台，是因为我们还需要先从 [3.1 近邻闲置](../3.1-neighborhood-exchange/README.md)验证最小流转，再经过 [3.2 近邻互助组](../3.2-neighborhood-mutual-aid-team/README.md)验证持续互助。只有跨社区的平台化需求被现实证明后，才重新启动本阶段。

## 当前暂缓的能力

- 跨社区的供需路由与扩张机制。
- 全局服务者发现、复杂推荐与排行榜。
- 多 Agent 咨询、转介和平台级会话编排。
- 平台级身份、信用、数据治理与商业分配机制。

重新启动前，必须证明平台层确有必要，并确认它不会把互助关系重新变成流量、排名和抽租关系。
