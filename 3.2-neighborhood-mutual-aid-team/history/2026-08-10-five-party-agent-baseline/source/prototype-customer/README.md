# 客户体验原型（CEP）

## 用途

验证潜在客户是否能够：

1. 快速理解“具体消费者分享本人亲历，帮助别人少踩坑”。
2. 看懂推荐依据、无推荐收益和非平台担保边界。
3. 区分消费者、消费者 Agent、服务者、服务者 Agent 与近邻系统 Agent。
4. 看懂消费者 Agent 可以代为补问和整理，但不能替消费者预约或付款。
5. 记住“真人亲历、Agent 不替人承诺、数据不出售”三个特点。
