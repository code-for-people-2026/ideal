# 阿里云百炼可用于“学生讲数学思路”视频验证的模型核查

- 核查日期：2026-08-27（Asia/Shanghai）
- 范围：仅阿里云百炼 / Model Studio 官方文档；未调用模型、未上传媒体。
- 目的：区分“整段视频画面＋视频原声联合理解”“只看视频画面”“只处理音频”，为 3 个视频的可重复对照实验选型。

## 结论先行

如果三个视频均与首个样本相近（约 255 秒、720p、带学生讲解原声），最干净的 `2 模型 × 3 视频` 主实验是：

1. `qwen3.5-omni-flash`（固定快照：`qwen3.5-omni-flash-2026-03-15`）
2. `qwen3.5-omni-plus`（固定快照：`qwen3.5-omni-plus-2026-03-15`）

两者都可通过 HTTP 一次传入完整视频文件，联合理解画面、语音和音效，并输出文本；均在华北 2（北京）公开可用，单视频上限 1 小时 / 2GB。因此首个约 255 秒、44MB 的视频适用。为保证 6 次结果可重复，正式评测应使用上述固定快照 ID，而非随时间更新的别名。

这里的“联合理解”有一个调用层面的必要条件：必须把媒体作为 `video_url` 视频文件传入。若改成 `type: video` 的图片列表，输入只剩预抽取画面帧，不能再利用原视频音轨。Qwen-Omni HTTP 调用还要求流式返回；只需文字时可设置 `modalities=["text"]`，但仍应保留 `stream=true`。

百炼还有很多可接收视频文件的模型，例如 `qwen3.8-max`、`qwen3.7-plus`、`qwen3.7-flash`、`qwen3.6-plus`、`qwen3.6-flash`、`qwen3.5-plus`、`qwen3.5-flash`、`qwen3-vl-plus`、`qwen3-vl-flash`。但官方明确说明这一路视觉模型**不理解视频文件中的音频**，只适合作为“视觉证据 / 试卷与板书识别”对照，不能代替学生思路的声画联合分析。

官方依据：[全模态模型列表与场景](https://help.aliyun.com/zh/model-studio/omni/)、[Qwen-Omni 用户指南](https://help.aliyun.com/zh/model-studio/qwen-omni)、[视觉理解模型与限制](https://help.aliyun.com/zh/model-studio/vision-model)、[模型价格总表](https://help.aliyun.com/zh/model-studio/model-pricing)。

### 抽帧参数的重要差异

- 通用 Chat API 的 `fps` 取值范围为 0.1–10，默认 2.0。
- 对 Qwen3.8 / Qwen3.7 / Qwen3.6 / Qwen3.5 / Qwen3-VL 等视觉模型，`fps` 可控制从视频文件抽取多少帧，也会告知模型帧间时间距离；因此会影响信息量、Token 和成本。
- 对 Qwen3.5-Omni，官方参数说明只把 `fps` 列为“告知相邻帧时间间隔”，没有列为控制视频文件抽帧频率的适用模型。因此，把 Omni 的 `fps` 从 2 改为 1 不应当被当作可靠的降费手段。
- Omni 官方 Token 估算示例内部使用 2 fps；Qwen3.5-Omni 最少 2 帧、最多 2048 帧，单帧和视频总像素预算另有限制。

这解释了首轮实测：请求中传了 `fps=1.0`，但仍返回约 151,472 个 `video_tokens`，与先前 2 fps 估算接近。正式 `2×3` 主实验应保持同一上传方式与提示词，不把该参数当成有效的 Omni 抽帧控制变量。

来源：[OpenAI 兼容 Chat 参数说明](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[Qwen-Omni Token 估算规则](https://help.aliyun.com/zh/model-studio/qwen-omni)。

## 三、仅音频路径

### A. 用相同 Omni 模型做“纯音频消融”

`qwen3.5-omni-flash` 和 `qwen3.5-omni-plus` 都能只接收从视频无损抽出的音频并直接输出分析文本。官方音频上限为 3 小时 / 2GB。这是最干净的纯音频消融：推理模型与提示词不变，只拿掉画面，便于判断错误来自听不清、看不清还是声画融合。

来源：[Qwen-Omni 模型选型与输入限制](https://help.aliyun.com/zh/model-studio/qwen-omni)、[语音识别模型列表中的 Omni 限制](https://help.aliyun.com/zh/model-studio/asr-model)。

### B. 专用 ASR，再交给文本推理模型

推荐 `qwen-audio-3.0-asr-flash-filetrans`：

| 项目 | 官方规格 |
|---|---|
| 北京可用 | 是，非实时 HTTP 文件转写 |
| 输入 / 输出 | 音频或含音轨的常见媒体文件 → 转写文本；不是数学推理模型 |
| 输入限制 | 公网 URL 单次 1 个；≤12 小时、≤2GB；支持 MP4、MOV、MKV、AAC、MP3、WAV 等；任意采样率 |
| 时间戳 | 固定开启，返回句级与字 / 词级毫秒时间戳，适合按口述时间对齐抽帧 |
| 其他能力 | 支持热词、Prompt 上下文、说话人分离；不支持情感识别 |
| 北京价格 | ¥0.00022 / 秒，输出不计费 |
| 新人免费额度 | 36,000 秒（10 小时），90 天；ASR 模型需在业务空间逐一开通权限 |

同系列 `qwen-audio-3.0-asr-flash` 也支持时间戳、URL/Base64 输入，价格相同，但单文件最长 5 分钟。三个样本若都稳定少于 5 分钟可用；为了避免边界和未来样本超长，`filetrans` 更稳妥。

首个 254.8 秒视频若无免费额度，单纯转写费用约为 `254.8 × 0.00022 = ¥0.056`，其后还需另计文本推理模型费用。

## 四、费用量级：用首轮实测 Token 做同长度估算

首轮 `qwen3.5-omni-flash` 实测用量：视频 151,472、音频 1,780、文本输入 660、文本输出 2,329 Token。

| 模型 | 按同样 Token 粗估 / 个视频 | 三个同长度视频粗估 |
|---|---:|---:|
| `qwen3.5-omni-flash` | 约 ¥0.398 | 约 ¥1.19 |
| `qwen3.5-omni-plus` | 约 ¥1.252 | 约 ¥3.76 |
| 两模型合计 | 约 ¥1.65 | 约 ¥4.95 |

这些是按公开原价、未扣新人额度的估算；真实费用取决于每个视频时长、画面分辨率、模型实际 Token 化、输出长度和控制台剩余额度。北京价格表名义上给每个 Omni 模型 100 万 Token 新人额度，若仍有效，6 次调用可能部分或全部被额度覆盖，但不可在未查看控制台前承诺为零费用。

## 五、对当前验证方案的建议

1. **主实验固定为 `qwen3.5-omni-flash-2026-03-15` 与 `qwen3.5-omni-plus-2026-03-15`，每个模型跑同样 3 个完整视频。** 两者都联合理解原声和画面，才是公平的 `2×3`。
2. 每次复用同一份提示词、输出字段、`max_tokens`、上传方式，并关闭联网搜索；记录原始响应、usage、耗时、模型精确 ID、文件 SHA-256。
   - 主实验必须使用 `video_url` 文件形式，不能误用图片列表形式，否则会静默变成无音轨的视觉实验。
   - Omni 调用保持 `stream=true`；只需要书面评测结果时使用纯文本输出。
3. 不把 `qwen3.8-max` / `qwen3.7-plus` / VL 系列混进声画联合主榜。若使用，单列为“视觉-only 对照”，只评题干 OCR、板书步骤和时间定位。
4. 可选增加两个消融：同一 Omni 只输入音频；`qwen-audio-3.0-asr-flash-filetrans` 转写＋时间戳对齐抽帧＋独立文本推理。
5. 先细化统一评分规约，再跑剩余 5 次；尤其要把“题目还原”“学生原话”“模型推断”“独立数学验算”分栏，避免首轮那种题干抄错却仍给高置信度的情况。

## 六、地域与额度注意事项

- 华北 2（北京）与新加坡等地域的 API Key、Endpoint、模型列表相互独立，不能混用；北京使用对应业务空间域名或 `dashscope.aliyuncs.com`。
- 免费额度只在北京地域提供；输入和输出 Token 共用模型额度。若想防止超额扣费，应在控制台开启“免费额度用完即停”。
- 上传媒体或调用 API 前仍应逐次说明服务、将上传什么、预计成本与临时文件保存规则，并取得明确同意。

来源：[地域、Endpoint 与 Key 隔离](https://help.aliyun.com/zh/model-studio/regions/)、[新人免费额度与用完即停](https://help.aliyun.com/zh/model-studio/new-free-quota/)。
