# 学生讲题视频验证

本目录只保存“学生对着数学题讲解自己思路”视频能力验证产生的**文本分析结果和运行记录**。

## 数据边界

本目录禁止保存或提交：

- 原始视频及其复制件；
- 提取的音频；
- 视频帧、截图、联系表或其他图像；
- 临时上传 URL、API Key、学生个人身份信息；
- 其他可还原学生影像或声音的媒体资产。

允许保存：

- 评测规范与提示词；
- 模型文本响应；
- Codex／人工核验报告；
- 不含凭证和临时媒体地址的 Token、费用、时延及运行元数据；
- 跨模型、跨视频的文字比较报告。

原始媒体和本地派生媒体继续保存在仓库外的私有实验目录，不进入本项目。

公开留档前，模型响应中识别出的账号姓名水印统一替换为 `[已脱敏账号水印]`；数学题面、时间戳、置信度和评测结论不受影响。

## 试运行说明

`pilot/` 中的首次 Qwen3.5-Omni-Flash 结果使用了早期的“视频理解＋数学判断合并”提示词。它用于发现问题和制定正式评测规约，不计入后续 `2 个模型 × 3 个视频` 的正式横评。

正式实验将对每个“模型 × 视频”单元分别保存：

1. 第一阶段视频证据包；
2. 第一阶段评分与致命错误标记；
3. Codex 第二阶段数学分析；
4. 模型原始文本响应；
5. 不含敏感数据的调用参数、Token、费用和时延记录。

每个视频还会生成一份双模型横向比较；三个视频完成后生成总报告。
