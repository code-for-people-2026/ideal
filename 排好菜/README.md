# 排好菜 · 领导评审工程原型

一个与 `街坊味/` 平级的独立菜单生成产品原型。当前只验证一条核心路径：

1. 生成周一至周五的午饭和晚饭，共 10 餐；
2. 每餐固定为 2 荤、2 素、1 汤；
3. 在三天横向对照视图中智能换菜或手动选菜；
4. 确认后进入只读的本周菜单总览并保存。

视觉、交互与规则以 Kith 用户原型为依据。旧菜单小程序代码不属于本原型的产品依据。

## 预览

```bash
cd prototype-engineering
npm ci
npm run dev
```

## 目录

- `prototype-engineering/`：可运行的移动端工程原型。
- `docs/review/`：Kith 参考图、最终页面截图与设计检查记录。

本目录是评审原型，不包含真实数据、登录、后端接口、菜品维护和订单功能。
